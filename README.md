# HopeBridge NGO

HopeBridge NGO is a responsive React.js + Tailwind CSS nonprofit website. It includes a modern mission-driven UI with Framer Motion animations, React Icons, glassmorphism cards, and fully responsive sections for programs, impact features, testimonials, and contact.

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- React Icons
- Vite

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Build for production:

   ```bash
   npm run build
   ```

## Notes

- The hero section uses a styled placeholder illustration card that can be replaced with branded nonprofit artwork later.
- The loading state is implemented in the React app to create a polished first impression.
